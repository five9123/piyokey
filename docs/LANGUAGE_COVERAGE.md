## 온보딩·첫 홈 계약

- 관심사 다음에 처음/자모/단어/문장의 4단계를 선택한다. 관심사와 동일한 **2열 카드**이며 아이콘 대신 `ㄱ · ㅏ`, `가 · 나`, `학교`, `같이 걷고 싶어요` 예시를 보여준다. 한국어 예시는 공통이고 설명은 현지화한다.
- 레벨 화면에는 돌아가기 버튼이 없다. 사전 선택 없이 선택 후 다음 활성화, 소개 스킵, 재실행 선택 복원은 유지한다.
- 첫 홈은 수준·관심사에 맞는 공식 덱을 추천한다. 다운로드나 부화 미션만으로 이어하기로 바뀌지 않으며 실제 학습 이후 전환한다.
- 기존 저장 단계 ID와 완료 사용자 상태, 부화 미션 gate를 유지한다. 한국어 예시는 기존 원문을 재사용한 정적 표시이며 새 발음/문제/음원을 추가하지 않았다.
