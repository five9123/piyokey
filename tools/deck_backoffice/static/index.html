AI·gTTS 연결 설정

API 키는 브라우저에 저장하지 않고 로컬 서버에서만 읽습니다. 음원을 만들 때 한국어 문구는 gTTS가 사용하는 Google Translate 음성 서비스로 전송됩니다.

  1. tools/deck_backoffice/config.example.env를 tools/deck_backoffice/.env로 복사합니다.
  2. OPENAI_API_KEY=...에 발급받은 키를 넣습니다.
  3. python3 -m pip install -r tools/requirements-audio.txt로 gTTS 2.5.4를 설치합니다.
  4. Deck Studio를 종료한 뒤 다시 실행합니다.
